# 📊 BudgetMate (Frontend)

BudgetMate is a personal finance tracking web application that helps users manage expenses, view transactions, and track budgets with an intuitive UI.

---

## 🚀 Features

* 🔐 **Authentication** (Signup, Login, Logout) with JWT
* 📈 **Dashboard** to view transactions and budget insights
* ➕ **Add / Edit / Delete transactions**
* 🌓 Responsive UI built with **Tailwind CSS**
* 🌍 Connected to **backend API** for secure data storage

---

## 🛠️ Tech Stack

* **React.js** (Frontend framework)
* **React Router DOM** (Client-side routing)
* **Tailwind CSS** (UI styling)
* **Axios** (API calls)
* **Context API** (Auth state management)

---
